Featured Project

Human Resource Management System

An enterprise-grade HRMS (Human Resource Management System) designed to streamline employee lifecycle operations across large organizations. Built with a modular Node.js backend and React-based frontend, it supports real-time leave tracking, role-based access, dynamic approval workflows, and multi-site configuration. Features include smart validation via stored procedures, audit-logged transactions, secure file handling via AWS, and interactive dashboards for HR analytics and compliance monitoring.
